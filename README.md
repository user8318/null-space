# null-space

## 空间准备

在需要存放空间文件的位置创建空间后，将本工具的所有脚本放入相同位置，并将空间文件命名为 `space.vhdx`。

如需修改空间文件名或格式，请在 `att.cmd` 和 `det.cmd` 中同步修改以下两项。`SPACE_NAME` 可使用 `.vhd` 或 `.vhdx` 扩展名；`RAW_NAME` 是卸载后使用的文件名，名称和扩展名都可以自定义。

```bat
set "SPACE_NAME=work.vhdx"
set "RAW_NAME=space.wav"
```

## 首次使用

运行一次 `setup.cmd`。它会将脚本所在目录直接加入当前用户的 Path，并隐藏该目录及其内容。

设置完成后，按 `Win+R` 打开“运行”，输入下方命令。若找不到 `att` 或 `det`，请重启“Windows 资源管理器”后重试。

## 日常使用

| 命令  | 作用                                                        |
| ----- | ----------------------------------------------------------- |
| `att` | 如文件为 `space.raw`，先改名为 `space.vhdx`，然后挂载空间。 |
| `det` | 卸载 `space.vhdx`，确认卸载后改名为 `space.raw`。           |

脚本静默执行，完成后命令窗口关闭。
